MasterOhad is a staff-management bot built for a Discord community around ER:LC, a Roblox emergency-response roleplay game. This page explains, plainly, what data the bot touches when it runs in a server and what happens to it.

01

What we collect

MasterOhad only collects data tied to the servers it's installed in and the members of those servers. Nothing is collected outside of Discord activity you generate.

Discord identity

User ID, username, and server roles — used to identify who a command or record belongs to.

Staff records

Infractions, promotions, leave-of-absence requests, and shift clock-in/out logs for staff members.

Roblox identity

Linked Roblox account ID and username, via the Bloxlink verification integration.

ER:LC session data

In-game joins, mod calls, and kill events pulled from the ER:LC API and tied to your Discord account.

Feedback & tickets

Staff feedback ratings you submit, and the contents of support tickets you open.

Message content

Read only for spam/link moderation and ticket transcripts — see section 03.

02

Why we collect it

Every field above exists to run a specific feature of the bot — staff scheduling, moderation, identity verification, or support tickets. None of it is used for advertising, profiling, or resale, and none of it leaves the servers that install the bot.

03

Presence & message content

Presence (online/offline status). Read live, in the moment a staff command runs (e.g. a member-count or dashboard command), to show how many members are currently online. It is never logged or stored — there is nothing kept to opt out of.

Message content. Used for two things only: scanning messages for spam, malicious links, and mass mentions as an automated moderation safeguard; and generating a transcript when a support ticket is closed, so both staff and the user have a record of the conversation. Spam-detection samples live only in memory for a short sliding window and are discarded automatically — never written to a database or file.

04

Storage & retention

Structured records — staff data, moderation history, verification links — are stored in a private MongoDB Atlas database, encrypted at rest. Data is kept for as long as needed to support these features, or until you request its deletion (section 06).

In practice

We do not currently run an automatic time-based purge — records persist until a staff member processes a deletion request, or the bot is removed from a server. If that changes, this page will be updated first.

05

Sharing & AI use

  • We do not sell or share your data with third parties.
  • Data is not used to train machine learning or AI models of any kind.
  • Roblox account data is exchanged only with the Bloxlink API for verification purposes.
06

Your rights & deletion

You can request removal of your data from our database at any time — no reason required.

How to request deletion

Open a support ticket in the Discord server where MasterOhad is installed and choose General Support. Our staff team will confirm and process the removal of your records.

07

Changes & contact

If this policy changes in a way that affects what we collect or how we use it, the "Last updated" date above will change and — where practical — server staff will be notified.

Questions about this policy, or the data described here, can be directed to server staff via the ticket system above, or by using the bot's /privacy command for a quick summary.
